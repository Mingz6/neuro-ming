What It Does

🧠

Real Personality

Not a generic assistant — Neuro-Ming has a personality profile mined from real conversations. It responds the way I would, with my interests and speaking style.

🔊

Voice Output (TTS)

Every response is spoken aloud via Azure OpenAI TTS. Mute/unmute toggle and click-to-replay on any message. Feels like a conversation, not a text box.

📱

Multi-Platform MCP

Connects to Teams, Outlook, iMessage, WeChat, and Apple Mail through MCP servers. Read messages, check calendar, draft replies — all from one chat.

⚡

Async & Fast

Built on FastAPI with async LLM and TTS calls. The event loop stays unblocked — responses feel instant even with voice synthesis.

🔌

6 LLM Providers

Swap between Azure OpenAI, OpenAI, Groq, Together AI, OpenRouter, and Ollama without changing code. Currently running GPT-5.2.

🛡️

Input Validation

4k character limit, empty input guards, proper HTTP error handling. No prompt injection, no abuse. Clean Pydantic schemas throughout.

How It Works

1 User sends a message in the chat UI
2 FastAPI validates input and loads conversation memory
3 Personality system prompt + history sent to Azure OpenAI GPT-5.2
4 LLM generates a personality-rich response
5 Azure OpenAI TTS synthesizes speech (mp3 audio)
6 Text + audio returned to browser — user reads and hears the reply

Built With
